# Incident response

1. Triage and assign an incident commander.
2. Preserve evidence with access controls and chain-of-custody notes.
3. Contain affected credentials, sessions, keys, endpoints or workers.
4. Assess confidentiality, integrity and availability impact.
5. Rotate/revoke compromised keys and invalidate sessions as required.
6. Notify affected parties and comply with applicable legal obligations.
7. Recover from known-good artifacts and verify controls.
8. Publish a post-incident review with corrective actions; exclude exploitable secrets.
