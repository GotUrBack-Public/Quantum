# Privacy review checklist

- Is each personal-data field necessary?
- Can account creation work without phone/email or address-book access?
- Are IPs, user agents and precise timestamps logged? For how long and by whom?
- Can identifiers be correlated across services or communities?
- Are push providers exposed to message content or social graph?
- Are read receipts, typing and presence optional?
- Are message bodies ever available to server-side moderation/search?
- Are E2EE and server-readable modes clearly distinguished?
- Are deletion, export, backup and key revocation behaviors documented?
- Are external analytics, fonts, CDNs and SDKs necessary?
- Does the threat model include traffic analysis and compromised endpoints?
